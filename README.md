# usage-band

Zeigt Sitzungslimit und wöchentliches Limit (in Prozent) in einem eigenen Fenster der Claude-Desktop-App. `/nutzung` öffnet das Fenster erneut.

## Installation

In der Desktop-App: Plus neben dem Eingabefeld, dann Plugins, Add marketplace mit `htwkarsten-blip/usage-band`, dann Add plugin `usage-band`.

Im Terminal:

```
claude plugin marketplace add htwkarsten-blip/usage-band
claude plugin install usage-band@karsten-mods
```
